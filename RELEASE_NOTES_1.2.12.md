# TG Monitor 1.2.12 — исправление повторов маленьких фотографий

У небольших фотографий Telethon мог сообщать размер восстановленной миниатюры,
но скачивать другую JPEG-версию меньшего размера. Целый файл ошибочно оставался
неполным и снова попадал в очередь.

Теперь размер и загрузка относятся к одной явно выбранной версии фотографии.
Обычная фотография предпочтительнее stripped-preview; для progressive/cached
и stripped-only вариантов учитывается соответствующий размер. JPEG дополнительно
декодируется перед публикацией. Обрезанные и повреждённые файлы остаются неполными.
При запуске существующие задания маленьких фотографий с ошибкой размера получают
одну внеочередную попытку; счётчики попыток и задержки остальных заданий сохраняются.

Проверено локально: 123 Python-теста, 13 JavaScript-тестов, smoke-тест готового EXE
в отдельном пустом архиве с переносом в папку с кириллицей, блокировкой второго
экземпляра и штатной остановкой. Пакеты проверены по явному списку файлов,
на отсутствие пользовательских данных и сохранённых секретов, ZIP проверены.

Updater предназначен только для перехода 1.2.11 → 1.2.12 на существующей установке.
Windows-пакет передаётся восемью частями `TGMonitor-Windows-x64.zip.part01`–`part08`:
установщик скачивает их с GitHub, проверяет каждую часть и собирает исходный ZIP.
SHA256 собранного ZIP: `541AB6CB928DD5DC0C84F8A1C88D1C297D0082FBFA66871EA99C134AAFF77453`.
Он скачивает пакет с GitHub и проверяет SHA256 до остановки приложения, сохраняет
прежний каталог данных, делает защищённую копию базы/настроек/сессий и проверяет
копию SQLite. После запуска проверяет версию, целостность базы, количество аккаунтов,
сообщений по аккаунтам и записей основных таблиц. Медиа не заменяются пакетом;
сохраняется манифест. При ошибке откатывается программа, база автоматически
не подменяется старой копией.

Этот выпуск не исправляет отдельную проблему авторизации Telegram-аккаунта.
Результат восстановления конкретных серверных вложений проверяется после установки.
