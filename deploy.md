# Развёртывание TG Monitor

Распакуйте Windows x64 сборку целиком. Персональная готовая версия создаёт config.ini из заранее подготовленных app-defaults.ini и новую базу в data; окна ввода API-ключей нет. Универсальная сборка и чистые исходники не содержат ключей: перед запуском подготовьте config.ini по config.example.ini, используя ключи приложения владельца сервера. Зависимости устанавливать не нужно; сборка не использует Python, пути, конфигурацию и данные компьютера разработчика. Интернет требуется для Telegram.

На сервере с рабочим столом можно использовать обычное окно приложения. Для фонового режима запускайте `"TG Monitor.exe" --headless --data-dir "D:\TGArchive"` под постоянной служебной учётной записью. Сначала подготовьте config.ini в выбранной папке данных; для персональной сборки его также создаёт обычный запуск с тем же --data-dir. В Планировщике задач укажите полный путь к EXE, аргументы --headless --data-dir и рабочую папку сборки. Включите запуск при старте Windows, запуск независимо от входа пользователя и перезапуск при ошибке; не ограничивайте длительность задачи. Установка задачи не выполняется автоматически. В исходниках scripts/install_keepalive.ps1 предназначен только для запуска исходной версии при входе текущего пользователя.

Панель по умолчанию слушает 127.0.0.1. Для доступа с другого компьютера используйте VPN или HTTPS-прокси и задайте panel_password в config.ini. Не выставляйте HTTP-порт прямо в интернет. Адрес bind и порт настраиваются в server.host/server.port.

Для обновления остановите программу, сохраните резервную копию data, замените EXE и _internal из новой сборки; сохранённый data не заменяйте. Схема базы обновляется при запуске. Для независимой новой установки используйте пустую папку data и свои ключи/аккаунты. Для переноса действующего архива остановите запись и копируйте config.ini, monitor.db*, sessions и media вместе. Журналы лежат в каталоге данных; ошибка запуска видна в run.log/launcher.log.

Проверенная сборка предназначена для Windows x64. Прочие архитектуры требуют собственной сборки. Проверка переноса в другую папку не заменяет тест на конкретной версии Windows Server; см. AUDIT.md.

На Windows Server Core без рабочего стола настройте config.ini вручную по config.example.ini в выбранной папке данных, затем запускайте --headless. Авторизуйте Telegram через веб-панель с другого компьютера по защищённому подключению. Команда «В папке» открывает Проводник на компьютере сервера и требует интерактивного рабочего стола; она не открывает серверную папку в локальном Проводнике удалённого клиента.
