# TG Monitor 1.2.2 — 2026-10-10

## Изменения

- Попытка входа по телефону получает идентификатор до отправки запроса: отмена работает и во время ожидания ответа сервера.
- Новая попытка ожидает подтверждения отмены предыдущей. Ошибка отмены показывается пользователю.
- Добавлены ограничения времени ожидания Telegram и очистка незавершённых попыток через 15 минут.
- Интерфейс показывает способ доставки кода, сообщённый Telegram, и понятные сообщения об ограничениях, неверном или просроченном коде.
- При переключении на телефон скрытая попытка QR-входа отменяется. Поздние ответы отменённых попыток не меняют новую форму.
- Обновлены кеш интерфейса и версия в API здоровья.

## Установка и обновление

Распакуйте `TGMonitor-Windows-x64.zip` целиком. Для новой установки запустите `TG Monitor.exe` и настройте свои API ID/API hash.

Для действующего сервера остановите приложение и сохраните согласованную резервную копию прежней папки данных: `config.ini`, `monitor.db*`, `sessions`, `media`. Распакуйте сборку в отдельную папку и запустите `"TG Monitor.exe" --headless --data-dir "путь к прежней папке данных"`. Сохраните прежние настройки локального адреса, пароля, HTTPS-прокси и автозапуска. Не заменяйте пользовательские данные содержимым сборки.

## Что проверено

Проверен синтаксис Python и JavaScript, выполнена сборка Windows x64 и запуск локальной исходной версии с ответом API здоровья. Перед публикацией проверены состав архивов и соответствие основных исходных файлов текущему проекту.

Тестовые наборы повторно не запускались. Получение реального кода Telegram и полный вход с реальным аккаунтом в рамках этого обновления не проверялись. Изменения устраняют обнаруженные проблемы обработки отмены и ожидания, но причина единичного сбоя доставки у разработчика не подтверждена.

Публикация этого релиза сама по себе не обновляет действующий сервер.
