# TG Monitor 1.2.5 — 13 октября 2026

Исправлена остановка загрузки истории на вложении, которое не успевает скачаться: если текст сообщения и состояние частичного файла уже сохранены, история продолжается со следующего сообщения. Вложение остаётся для последующего восстановления, частичный файл не удаляется. В пределах одного прохода по чату такое вложение не скачивается повторно.

Если сообщение ещё не сохранено, таймаут по-прежнему приводит к повтору без продвижения контрольной точки истории. Отмена при паузе сохраняет прежнее поведение.

Получение данных участников группы ограничено по времени. Панель показывает ожидание ограничения частоты запросов Telegram и оставшиеся секунды.

Схема базы не меняется. Конфигурация, Telegram-сессии и существующие медиа не входят в сборку. Вложение, не скачанное полностью, не объявляется успешно сохранённым.
