# TG Monitor 1.2.16 — меньше работы CPU при загрузке истории

Включён нативный cryptg0.6.0 для шифрования Telegram; готовая Windows-сборка проверяет фактический backend через health. Запись выполняется выделенным потоком с собственным постоянным соединением SQLite. Повторные сведения об аккаунте, чате и авторе обрабатываются один раз внутри пакета; сообщения, задания вложений и checkpoint по-прежнему фиксируются одной транзакцией. Размер порции истории адаптируется от25 до100 сообщений по времени ожидания и записи. Приём новых сообщений, ограничения Telegram и паузы между порциями сохранены.

SQLite остаётся в WAL с synchronous=FULL; при ошибке транзакция откатывается. Повторная отмена задачи дожидается завершения записи перед освобождением writer. При остановке очередь дренируется, соединение закрывается в своём потоке, затем выполняется checkpoint. Изменений схемы базы и интерфейса относительно1.2.14 нет; отложенный интерфейс1.2.15 не включён.

Локальный одноразовый тест с50000 существующих сообщений/заданий: запись5000 новых сообщений через фактический write_call — медиана4.021s/1.563sCPU на1.2.14 против0.429s/0.281sCPU при100 сообщениях в пакете в новой версии. Это изолированная запись без сети Telegram, не обещание такого же ускорения всей истории на сервере. Проверены целостность, количество сообщений/заданий, checkpoint и FULL. Отдельные процессы аварийно завершались до и после commit: данные оставались согласованными.

Проверено142 Python-проверки (полный набор141 и дополнительная проверка остановки writer) и13 JavaScript-тестов. Windows EXE проверен с переносом, отдельным временным архивом, нативным cryptg, восстановлением синтетического сообщения из spool, защитой от второго экземпляра и сохранением данных после штатной остановки.

Установщик предназначен для существующей1.2.14→1.2.16, проверяет SHA256 опубликованных частей и пакета, делает защищённую резервную копию базы/настроек/сессий и проверяет сохранность данных после запуска. Медиа остаются в прежнем каталоге. После обновления проверяется crypto_backend=cryptg.
