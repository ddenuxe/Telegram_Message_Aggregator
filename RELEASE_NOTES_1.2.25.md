# TG Monitor 1.2.25

Версия включает всё из 1.2.24 (одинаковые вложения хранятся на диске один раз) и
две новые возможности.

## Из видео сохраняются только кружки

Видеосообщения-кружки, записанные в самом Telegram, скачиваются как раньше. У обычных
видео сохраняется само сообщение — текст, дата, отправитель и отметка «видео», — но
файл не скачивается и не ставится в очередь загрузки. В чате такое сообщение
подписано «не скачано: из видео сохраняются только кружки». Фото, голосовые, аудио и
файлы сохраняются как раньше.

Уже скачанные видео остаются на диске и открываются из панели как прежде. Недокачанная
часть видео тоже остаётся на месте, но загрузка не продолжается. Отдельное видео можно
скачать вручную: в разделе «Файлы» у него есть кнопка «Скачать это видео». Обычные
видео больше 1 ГБ не попадают в список файлов, ожидающих решения.

## Кнопка «Подключить заново»

Если Telegram завершил сеанс аккаунта (например, сеанс закрыли в «Настройки →
Устройства» или Telegram сбросил его сам), в карточке аккаунта теперь есть кнопка
«Подключить заново». После входа в этот же Telegram-аккаунт по QR-коду или номеру
архив продолжается под тем же аккаунтом, без дублей: накопленные загрузки фото и
данных аккаунта продолжаются автоматически.

## Надёжность объединения одинаковых файлов

Перед заменой копии ссылкой содержимое двух файлов теперь сравнивается байт в байт.
В Windows время изменения файла обновляется с шагом около 15 мс, поэтому файл того же
размера, переписанный сразу после подсчёта контрольной суммы, мог пройти прежнюю
проверку по размеру и времени. Теперь такой файл никогда не заменяется.

## Обновление

База сообщений `monitor.db` не перестраивается и не копируется заново. Сообщения с
обычными видео, которые ждали загрузки, помечаются как «не скачано» по мере обработки
очереди.

Проверки: тесты Python и JavaScript на Windows/Python 3.14, в том числе пропуск
обычного видео без задания загрузки, загрузка кружка, сохранение уже скачанного и
недокачанного видео, ручная загрузка видео и кнопка повторного входа.
