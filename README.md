# TG Monitor

Архив Telegram с веб-панелью: несколько аккаунтов, личные и групповые чаты, поиск сообщений, вложения и очистка локального архива.

## Исходники

Полный актуальный проект находится в [tg-monitor-open-source.zip](tg-monitor-open-source.zip). Скачайте и распакуйте архив: исходники находятся в папке `tg-monitor`. Внутри — `app.py`, `launcher.py`, `frontend`, `scripts`, `tests`, `docs`, зависимости и лицензии. Рабочие базы, переписки, сессии и API-ключи в архив не включены.

Финальное обновление от 6 октября 2026: исправлены ошибки входа и отмены подключения, восстановление кнопок после ошибок и оформление карточки подключения; инструкции и инструменты упорядочены.

Исходники требуют Python и установки `requirements.lock`. Запуск без ручного ввода ключей требует заранее подготовленной конфигурации приложения. Чистые исходники собственных ключей не содержат.

## Обновление первоначальной настройки

Запустите start_monitor.bat из распакованной папки. После подготовки Python откроется графическое окно для ввода API ID и API hash. Ключи сохраняются один раз; при повторном запуске открывается панель. Ключи приложения и вход в Telegram-аккаунты через QR-код — разные этапы. В режиме --headless конфигурация должна быть подготовлена заранее.
