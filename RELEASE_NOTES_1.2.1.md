# TG Monitor 1.2.1 — 2026-10-09

## Изменения

- Раздельное состояние занятости QR-входа и входа по телефону.
- Отмена сразу освобождает форму для новой попытки.
- Каждая попытка входа по номеру имеет свой идентификатор в интерфейсе: запоздалый ответ не меняет новую попытку и не разблокирует её кнопки.
- Запоздало созданное подключение отменённой попытки закрывается через API.
- Обновлена версия файла интерфейса для сброса браузерного кеша.
- API здоровья сообщает версию 1.2.1.

## Установка и обновление

Распакуйте `TGMonitor-Windows-x64.zip` целиком. Для новой установки запустите `TG Monitor.exe` и настройте свои API ID/API hash.

Для действующего сервера сначала остановите запись и сохраните согласованную резервную копию прежнего каталога данных, включая `config.ini`, `monitor.db*`, `sessions`, `media`. Распакуйте новую сборку в отдельную папку и запустите `"TG Monitor.exe" --headless --data-dir "путь к прежнему каталогу данных"`. Не заменяйте пользовательские данные содержимым сборки. Сохраните локальный bind, пароль и HTTPS-прокси.

## Ограничения проверки

Тестовые наборы в рамках этого обновления повторно не запускались. Доставку реального кода Telegram после отмены нужно проверить с аккаунтом владельца; автоматическая отправка кодов на реальные номера не выполнялась.
