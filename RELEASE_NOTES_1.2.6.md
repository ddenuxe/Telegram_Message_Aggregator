# TG Monitor 1.2.6 — 13 октября 2026

Действия с сохранёнными вложениями теперь зависят от способа открытия панели:

- На компьютере с приложением, через локальный адрес `http://127.0.0.1:8090`, кнопка «В папке» открывает Проводник и выделяет исходный файл. Работает в переписке, общем разделе файлов и списке файлов для очистки.
- Через домен или с другого устройства кнопка «Скачать» скачивает существующий файл на это устройство, без перехода в каталог сайта.

Фоновый запуск Windows поддержан: открытие папки передаётся в единственный пользовательский сеанс с запущенным Проводником. Временная задача удаляется после выполнения. Если такого сеанса нет или открыто несколько сеансов, панель сообщает об ошибке вместо ложного успеха.

Открытие папки разрешено только из прямой локальной панели; запросы через прокси, удалённые и межсайтовые запросы отклоняются. Файл выбирается по записи базы, путь проверяется внутри хранилища. Несуществующие и неполные вложения не выдаются как полные.

База, сессии и существующие медиа не заменяются; схема базы не меняется.

Проверки перед публикацией: 37 проверок Python, 12 проверок интерфейса, синтаксис обеих команд Windows-помощника и отдельный запуск готового Windows EXE с временной базой. Практическая установка и проверка Проводника на рабочем сервере выполняются отдельно после публикации.
