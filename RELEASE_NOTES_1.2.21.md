# TG Monitor 1.2.21

Добавлены шкалы загрузки истории для каждого аккаунта и общий итог: процент, сохранено из общего количества и сколько осталось. Общий процент учитывает объём сообщений, а не средний процент аккаунтов.

Объём запрашивается у Telegram без скачивания сообщений, с общим ограничением частоты и регулятором CPU. Пока он неизвестен, панель показывает «Считаем общий объём». Проценты приблизительные: доступная история в Telegram может меняться. 100% появляется после завершения всех чатов; скачивание фото и видео отображается отдельно.

Прогресс хранится в базе и обновляется вместе с записями. Обновление панели не пересчитывает архив. Существующие сообщения, сессии и файлы сохраняются; механизм продолжения истории и ограничения CPU из 1.2.20 сохранены.
