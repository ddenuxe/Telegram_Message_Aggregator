# TG Monitor 1.2.9

## Загрузка вложений

- Незавершённые документы и видео продолжают скачиваться с сохранённого места. Уже полученную часть файла программа не загружает заново.
- Полностью скачанный временный файл публикуется при повторе без нового запроса к Telegram.
- Очередь сначала обрабатывает новые и небольшие вложения. Работа по одному аккаунту остаётся последовательной, чтобы не перегружать его соединение.
- Фото, которые Telegram многократно возвращает меньше заявленного размера, остаются помеченными как неполные и проверяются реже. Маленькую копию программа не выдаёт за полный оригинал.
- Текст сообщений по-прежнему сохраняется отдельно от загрузки файлов.

## Проверки и обновление

Пройдено 110 автоматических проверок Python и проверен запуск готового Windows EXE в отдельной папке. Обновление с 1.2.8 создаёт защищённую резервную копию базы, конфигурации и сессий, проверяет целостность SQLite и сохраняет существующую папку медиа. Пользовательские данные, ключи и сессии в выпуск не включены.

Неполные фото могут по-прежнему требовать отдельной проверки на стороне Telegram; счётчик очереди не означает потерю текста сообщений.
